功能介绍
--------
Trae 安装包制作工具是一款强大的 Windows 安装程序制作工具，
支持图形界面和命令行两种模式，兼容 Inno Setup 脚本格式。

主要功能：
- 一键生成安装包（setup.exe）
- 5步安装向导（欢迎页、许可协议、目录选择、安装进度、完成页）
- 支持自定义许可协议声明
- 支持选择其他磁盘进行安装
- 自动创建快捷方式（开始菜单和桌面）
- 自动生成卸载程序
- 注册表注册卸载信息

系统要求
--------
- Windows 7 或更高版本

快速开始
--------

方法1：直接运行（推荐）
  双击 TraeInstallerCreator.exe 启动图形界面

方法2：命令行模式
  TraeInstallerCreator.exe script_file.iss [选项]

使用步骤（图形界面）
--------------------

第1步：基本设置
  在"基本设置"标签页中填写：
  - 应用名称（AppName）：如"我的程序"
  - 应用版本（AppVersion）：如"1.0"
  - 默认安装目录：如"{autopf}\我的程序"
  - 输出目录：选择安装包保存位置
  - 输出文件名：如"setup.exe"

第2步：添加文件
  在"文件管理"标签页中：
  - 点击"添加文件"按钮选择要打包的文件
  - 点击"添加文件夹"按钮智能添加整个文件夹
  - 文件将自动保存到安装目录

第3步：许可协议
  在"许可协议"标签页中：
  - 系统已预置中文许可协议模板
  - 可自定义协议内容
  - 用户安装时必须同意协议才能继续

第4步：快捷方式
  在"快捷方式"标签页中：
  - 添加开始菜单快捷方式：{group}\程序名
  - 添加桌面快捷方式：{autodesktop}\程序名

第5步：生成安装包
  点击工具栏的"一键生成安装包"按钮
  或点击"构建安装程序"按钮
  等待生成完成，会自动打开输出目录

安装包使用说明
--------------

安装过程：
  1. 双击生成的 setup.exe
  2. 点击"下一步"查看欢迎页面
  3. 阅读许可协议并勾选"我同意"
  4. 选择安装目录（可点击"浏览"选择其他磁盘）
  5. 点击"安装"开始安装
  6. 安装完成后点击"完成"

卸载程序：
  通过开始菜单 -> 程序组 -> 卸载程序
  或通过控制面板 -> 程序和功能 -> 卸载

脚本格式（.iss）
----------------
兼容 Inno Setup 脚本格式：

[Setup]
AppName=我的程序
AppVersion=1.0
DefaultDirName={autopf}\我的程序
Compression=zip
OutputDir=output

[Files]
Source: "MyProg.exe"; DestDir: "{app}"
Source: "Readme.txt"; DestDir: "{app}"; Flags: isreadme

[Icons]
Name: "{group}\我的程序"; Filename: "{app}\MyProg.exe"
Name: "{autodesktop}\我的程序"; Filename: "{app}\MyProg.exe"

[License]
LicenseText=最终用户许可协议内容...

常见问题
--------

Q: 点击生成按钮后没有反应？
A: 请检查是否已填写应用名称和版本号，确保输出目录存在。

Q: 生成的安装包在哪里？
A: 默认保存在"输出目录"指定的文件夹中。
   注意：生成的是一个文件夹（包含 setup.exe 和相关文件），
   不是单个独立的 exe 文件。

Q: 安装时提示找不到 DLL？
A: 请确保安装包文件夹中的所有文件都完整，不要单独复制 setup.exe。

Q: 如何自定义许可协议？
A: 在"许可协议"标签页中直接编辑文本内容即可。

Q: 能否选择其他磁盘安装？
A: 可以，在安装向导的"选择安装目录"页面点击"浏览"按钮即可。
